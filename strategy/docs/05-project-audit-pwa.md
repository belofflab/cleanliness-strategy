Серьёзность: 🔴 критично для запуска · 🟠 важно · 🟡 желательно.

## 5.2 Бренд и домен

- «Точка Чистоты» — русское название, требования закона о русском языке к самому бренду не возникают.
  Остальная информация для потребителя тоже на русском.
- Домен латинский и **не совпадает с названием** (cleanliness ≠ «Точка Чистоты»). Клиент, которому порекомендовали
  «Точку Чистоты», не угадает адрес сайта. Варианты: кириллический домен с названием бренда (проверить
  доступность) с 301-редиректом, `t.me/pointclean` и визитки с QR — на бренд.
- В подвале «© Blanq Tech», почта на blanq.tech, Telegram — `pointclean`: три разных имени. Привести к одному.
- Перед масштабированием в новые города проверить товарный знак «Точка Чистоты» (Роспатент): название
  распространённое, в Тюмени по запросу в 2ГИС могут найтись однофамильцы.

## 5.3 PWA: есть ли смысл — с учётом того, что уже есть Expo-приложение

**Факты:** у проекта есть Expo-приложение (SDK 54) с клиентским букингом. Оно не опубликовано в сторах и
тестируется через Expo Go или APK. `manifest.ts` есть, но в нём только `favicon.ico`, без иконок 192/512 и
без service worker — **сайт сейчас не устанавливается как PWA**.

| Аудитория | Рекомендация | Почему |
|---|---|---|
| **Разовые клиенты (тип A)** | Ни приложение, ни PWA не нужны | Заказ раз в несколько лет. Нужны цена в квизе, бронь слота на сайте и ответ в MAX/Telegram за 7 минут |
| **Подписчики (тип B)** | **PWA на базе Next.js** — личный кабинет на `tyumen.cleanliness.pro/account` | Один код с сайтом; без App Store и Google Play (публикация для российского юрлица — платный аккаунт, модерация, ограничения платежей); установка по ссылке из сообщения. Запуск — когда появятся подписки (≥ 40–50 активных, в реалистичном сценарии — апрель–май 2027) |
| **Клинеры** | **Expo-приложение** (как и планирует SYSTEM_AUDIT): APK для Android-клинеров + PWA-фолбэк для iOS | Нужны камера, офлайн-очередь фото и чек-листов, фоновая геолокация — нативное приложение надёжнее. Распространение внутреннее, сторы не нужны. Запуск — с 6–8 клинеров (M4–M5) |
| **Мессенджеры** | Бот в MAX (основной) и Telegram | Напоминания, «повторить уборку», оценка визита, партнёрские лиды. Push в браузере и Expo в РФ доставляются нестабильно — критичное дублируйте в мессенджер |

**Не тратить ресурс** на публикацию клиентского Expo-приложения в App Store до появления подписки и оплат:
для разового клиента оно не нужно, а для подписчика PWA быстрее и дешевле.

**Минимум, чтобы сайт стал устанавливаемым (≈ 0,5 дня):** иконки 192 и 512 PNG (+ maskable) в `manifest.ts`,
городские `name`/`description`, `start_url` с городом, service worker с офлайн-страницей. Проверка — Chrome
DevTools → Application (в Lighthouse 12 отдельной PWA-категории больше нет); на iOS — «На экран Домой»
(web push только для установленной PWA, iOS 16.4+).

**MVP клиентского кабинета (PWA):** ближайший визит и клинер · перенос и пропуск в 2 касания · пауза подписки ·
оплата и чеки · оценка визита (≤ 3 → звонок бригадира) · допуслуги к визиту · фотоотчёт · промокод для друга.
Бэкенд для этого уже частично есть: `/mobile/orders`, `/mobile/notifications`, `/auth/otp/*`. Не хватает
`subscriptions`, `payments`, `order_media`.

**Метрики успеха PWA:** ≥ 50% подписчиков установили · ≥ 70% переносов без звонка · отток подписки ≤ 7–9% ·
фотоотчёт в 100% заказов (через приложение клинера).
