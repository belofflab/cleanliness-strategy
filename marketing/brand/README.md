# Логотипы «Точки Чистоты»

Комплект построен на действующем знаке сайта (`apps/web/app/icon.svg`, `apps/web/components/Logo.jsx`):
капля с точкой в скруглённом квадрате с градиентом и искра. Надпись — Manrope SemiBold: «Точка» тёмным,
«Чистоты» фирменным синим. **Во всех файлах текст переведён в кривые** — шрифт для открытия не нужен.

## Файлы

Каждый логотип есть в трёх форматах: `svg/` — вектор для сайта и дизайнеров, `pdf/` — вектор для типографии,
`png/` — растр с прозрачным фоном (2000 px по ширине). Файлы `*_preview-on-navy.png` показывают вариант на
тёмном фоне.

| Файл | Где использовать |
|---|---|
| `logo-horizontal_color` | Основной: сайт, документы, светлый фон |
| `logo-horizontal_color-dark` | Тёмный фон: обложки, видео, баннеры |
| `logo-horizontal-descriptor_color(-dark)` | С подписью «клининговая служба»: визитки, листовки, карточки на картах |
| `logo-stacked_color(-dark)` | Вертикальный: квадратные форматы, обложки клипов, фартук |
| `logo-horizontal_1c-blue / -white / -black` | Одним цветом: шелкография, вышивка, гравировка, факс-бланки |
| `logo-stacked_1c-blue / -white` | Вертикальный одним цветом |
| `logo-mark_color / 1c-*` | Знак без надписи: аватар, иконка, кепка, рукав, наклейки |
| `vk-avatar_1000.png`, `vk-avatar_400.png` | Аватар сообщества VK (обрезается кругом, искра остаётся внутри круга) |

## Цвета

| Цвет | HEX | RGB | CMYK (ориентир) | Pantone (ближайший) | Роль |
|---|---|---|---|---|---|
| Небесный | `#0EA5E9` | 14 · 165 · 233 | 75 · 15 · 0 · 0 | 2995 C | Начало градиента, точка в капле, акценты |
| Глубокий синий | `#0369A1` | 3 · 105 · 161 | 100 · 45 · 5 · 10 | 3015 C | «Чистоты», конец градиента, одноцветный логотип |
| Чернильный | `#0F172A` | 15 · 23 · 42 | 80 · 65 · 40 · 80 | Black 6 C | «Точка», основной текст |
| Светлый | `#E0F2FE` | 224 · 242 · 254 | 10 · 0 · 0 · 0 | 656 C | Искра, фоны плашек |
| Тёмно-синий (фон, ткань) | `#0B2A4A` | 11 · 42 · 74 | 100 · 75 · 35 · 40 | 2965 C | Тёмный фон, цвет формы |

CMYK и Pantone — ориентиры для типографии. Перед тиражом утвердите цвет по веерку или пробному оттиску:
синий на ткани и бумаге ведёт себя по-разному.

## Правила

- **Охранное поле** — не меньше 1/4 высоты знака со всех сторон. Внутрь не заходят текст, края фото, другие логотипы.
- **Минимальный размер:** горизонтальный логотип — 30 мм в печати и 120 px на экране; знак — 10 мм и 24 px.
  Для вышивки: горизонтальный — от 70 мм, знак — от 25 мм (иначе искра и точка «слипнутся»).
- **Градиент** — только в полноцветной печати (DTF, офсет, цифра) и на экране. Шелкография, вышивка, плоттер,
  гравировка — только одноцветные файлы `1c-*`.
- **Нельзя:** растягивать и наклонять, менять шрифт и цвета надписи, перекрашивать знак в другие цвета,
  добавлять тени и обводки, ставить цветной логотип на пёстрое фото (используйте `color-dark` или `1c-white`
  на затемнённой плашке).
- **Название** пишется «Точка Чистоты» — с прописных, без кавычек в логотипе. В тексте: «Точка Чистоты»
  или «клининговая служба «Точка Чистоты»».

> В открытых источниках есть другие компании с названием «Точка Чистоты». Перед тиражами формы, вывесок
> и рекламой проверьте товарный знак в Роспатенте (блок 5.2 стратегии).

## Пересборка

```bash
pip install fonttools brotli uharfbuzz segno   # Playwright и Chromium нужны для PNG/PDF
python3 marketing/tools/build_brand.py
```

Шрифт Manrope лежит в `marketing/fonts` (лицензия SIL OFL 1.1, `OFL-Manrope.txt`).
